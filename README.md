# FLAT Grammar Learning Platform

## About the Project

FLAT Grammar Learning Platform is an interactive web application developed for learning Formal Languages and Automata Theory concepts.

The project focuses on:
- Left Recursion
- Left Factoring

## Features

- Interactive learning interface
- Left Recursion explanation and examples
- Left Factoring explanation and examples
- Grammar transformation simulator
- Interactive quiz
- Quiz timer and progress tracking
- Certificate generation

## Technologies Used

- HTML
- CSS
- JavaScript
- React / Remix
- Vite

## Purpose

This project is developed as a learning application for students to understand important FLAT concepts through an interactive and user-friendly interface.

## Project Topic

Formal Languages and Automata Theory (FLAT): Elimination of Left Recursion and Left Factoring

# FLAT Grammar Learning Platform

## About the Project

FLAT Grammar Learning Platform is an interactive web application
designed to help students understand important concepts of
Formal Languages and Automata Theory (FLAT).

The main focus of this project is **Left Recursion** and
**Left Factoring**, which are important techniques used in
context-free grammar transformation and parsing.

### Left Recursion
Left recursion occurs when a grammar production derives a
non-terminal from itself on the left side. The project explains
how left recursion can be identified and eliminated.

### Left Factoring
Left factoring is a grammar transformation technique used when
two or more productions have a common prefix. The project explains
how common prefixes can be removed to make the grammar suitable
for parsing.

## Features

- Interactive learning content
- Left Recursion examples
- Left Factoring examples
- Grammar simulator
- Interactive quiz
- Quiz timer and progress tracking
- Certificate generation
  
## Technologies Used

- HTML
- CSS
- JavaScript
- React / Remix
- Vite

## Purpose

The purpose of this project is to provide students with a simple,
interactive, and visual way to learn and practice Left Recursion
and Left Factoring concepts.
